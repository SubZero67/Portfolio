    How I work

    1. Measure

      Capture real readings with calibrated instruments.

    2. Analyse

      Compare readings against limits and look for patterns.

    3. Find the root cause

      Trace the symptom back to what is actually wrong.

    4. Report

      Write findings and fixes so the client can act on them.
